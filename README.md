# ML26

A small machine-learning learning repository organized around day-based exercises and study material.

## Repository contents
The current repository includes a day01 directory, a README, and an index.html page. Treat individual exercises as independent learning activities unless the source code defines a shared application workflow.

## Explore
```bash
git clone https://github.com/nyohleonard-nlktech/ml26.git
cd ml26
```

Open index.html in a browser to view the landing page. Explore the day01 directory for the first set of materials.

## Suggested workflow
1. Read the exercise instructions.
2. Install only the dependencies required by that exercise.
3. Run the code and record observations.
4. Add a short explanation of the concept and expected output.
5. Include reproducible sample data and tests where useful.

No single runtime or dependency set is declared for the entire repository. No license file is present; all rights reserved unless an explicit license is added.
