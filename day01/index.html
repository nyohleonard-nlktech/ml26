01 — The Field Map

Containment, not synonyms

AI, ML, and DL are nested sets — each one a strict subset of the one before it. Data Science is not part of that chain; it overlaps it. Conflating these four is the single most common category error in how people talk about this field.

Artificial Intelligence
Machine Learning
Deep Learning
Data Science
Artificial Intelligence
The broadest set: any system that perceives its environment and takes actions to achieve a goal, judged by whether it acts rationally — not by whether it "learns." Rule-based expert systems and search algorithms (A*, minimax) are AI without being ML. Click a region or a term above to compare.
02 — Formal Definitions

Say it the way the field says it

Working definitions you can defend in an interview, not marketing copy.

"A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
— Tom Mitchell, Machine Learning (1997) — the field's canonical definition

Deep Learning — machine learning where the hypothesis function is a composition of many nonlinear layers (a neural network), so the model learns its own feature representations from raw data instead of relying on hand-engineered features. "Deep" refers to the number of layers, not the sophistication of the result.

Data Science — the discipline of extracting knowledge and decisions from data using statistics, programming, and domain expertise. ML is one tool a data scientist reaches for; SQL, hypothesis testing, causal inference, and visualization are others. Not every data science task involves a trained model — that's the distinguishing property.

04 — What "Learning" Means, Formally

It's an optimization problem

Strip away the metaphor. Every supervised learning algorithm you'll touch this month is one instance of the same statement:

θ*  =  argminθ   (1/n) Σᵢ L( fθ(xᵢ), yᵢ )  // empirical risk minimization
f_θ — the hypothesis function (linear model, tree, neural net) parameterized by θ
(xᵢ, yᵢ) — the i-th training example: input and true label
L(·,·) — a loss function measuring how wrong f_θ(xᵢ) is versus yᵢ
θ* — the parameters that minimize average loss over the training set

"Training a model" means running an optimizer (typically gradient descent) to search for θ*. "Generalization" is the gap between loss on the training set and loss on data the model never saw — the entire practice of ML engineering (train/val/test splits, regularization, cross-validation) exists to manage that gap, not the training loss itself.
